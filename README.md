# 🐍 Snakstract

**Stake. Slither. Survive.**

Snakstract is a PvP snake game built on Abstract chain (Ethereum L2). Stake ETH, battle, grow by consuming others, and escape to win. Miss your chance, and you’ll lose it all.

## 🔥 Features
- Stake ETH in preset/custom amounts
- Escape timer mechanic
- ETH orb drop logic on player death
- Orb sparkle colors (green > yellow > red)
- Leaderboard of top 11 earners
- Manual + backup withdraw
- Referral system (3% fee: 2% to treasury, 1% to referrer)
- Treasury owned by multisig
- ETH price ticker + Relay.link bridge
- History tab for past games
